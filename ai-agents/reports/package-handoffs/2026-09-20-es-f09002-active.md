## Reconstructed failure
Current main called `guild.retrieveAuditLogs().type(MEMBER_ROLE_UPDATE).limit(100).complete()`. JDA defines PaginationAction `limit(int)` as the number retrieved per request, not a total iteration limit. Calling `complete()` therefore retrieved only one page. Once 100+ unrelated newer role updates displaced the owned D07 assignment, the latest relevant target/role observation was absent, `MUTE_ROLE_OWNERSHIP_UNVERIFIED` retried forever, and a temporary managed mute could remain after expiration.
