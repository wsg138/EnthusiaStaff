## Status vocabulary for new documentation

- **Desired:** signed-off requirement/goal, not necessarily implemented.
- **Merged:** the behavior has source and tests on `main` at an exact revision; do not translate automatically to production.
- **Staging / shadow / default-off:** enabled only in a bounded environment or inert mode; tests do not grant authority.
- **Owner-reported live:** owner stated a specific artifact is installed; identify the JAR/backend/version and date.
- **Verified live:** precise runtime, configuration, backend and observed behavior backed by logs/attestation/checks. Do not label anything verified live just because a release PR merged.
- **Unknown / disputed:** evidence does not establish one of the above or docs contradict; record the missing proof.
